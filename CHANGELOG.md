# Changelog

## 1.0.0 — 2026-10-08

Первый релиз EDU ERP (ТЗ v1.0).

**Ядро**
- Laravel 12, PHP 8.2+, MySQL 8 / MariaDB; работает на shared hosting (Beget) без VPS, Docker и Node.js-сервера.
- Мультиарендность: `organization_id` во всех сущностях, глобальный TenantScope, фильтр по филиалам (Все филиалы / один).
- Роли и права (Super Admin, Директор, Администратор, Sales Manager, Преподаватель, Бухгалтер + собственные роли), Gates на каждое право.
- Журнал действий (старые → новые значения, IP, user agent), soft delete, транзакции в сервисах.

**Модули**: CRM (лиды, воронка, конвертация), ученики и родители, курсы, группы (история переводов), преподаватели и сотрудники,
расписание с проверкой конфликтов преподавателя/аудитории/группы, занятия, посещаемость, оплаты / возвраты / коррекции, долги,
расходы, зарплаты (фикс, за занятие, за ученика, процент), Telegram-уведомления, дашборд и аналитика, экспорт CSV/PDF.

**Платформа**: REST API `/api/v1` (Sanctum), webhook лидов, резервное копирование БД (cron + восстановление), cron-расписание,
интерфейс ru / uz, адаптивный UI с нижней навигацией, demo-данные, 82 автотеста (SQLite + MySQL).
