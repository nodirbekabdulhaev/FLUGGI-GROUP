# Тема Vesmir (ACF)

Установка: Внешний вид → Темы → Добавить → загрузить `vesmir-theme.zip` → активировать. Нужен плагин **ACF** (для повторителей и страницы настроек — ACF PRO).

Поля создаются кодом (`inc/acf-fields.php`), ничего импортировать не надо.

## Где что менять
**Главная страница** (Страницы → Главная, назначить её в Настройки → Чтение → «Статическая страница»):
вкладки Первый экран / Галерея / О компании / Для кого / Блог / Контакты и форма. У каждой секции есть переключатель «Показывать секцию».

**Настройки сайта** (пункт меню в админке): логотипы, 3 цвета бренда, кнопка в шапке, телефон/e-mail/адрес/карта, соцсети, e-mail для заявок, футер, коды счётчиков.

**Меню**: Внешний вид → Меню (области «Главное меню», «Меню в футере»). Пока меню не собрано, выводятся якоря по умолчанию. Переключатель языков TranslatePress добавляется в меню как обычно.

Пока поле пустое, тема показывает контент с текущего vesmir.uz (`inc/defaults.php`). Картинки по умолчанию ссылаются на файлы старого сайта — загрузите их в ACF-поля.

## Формы
Заявка и подписка уходят через `admin-post.php` письмом на e-mail из «Настройки сайта → Формы» (иначе на e-mail администратора). Защита: nonce + honeypot. Для надёжной доставки поставьте SMTP-плагин.
